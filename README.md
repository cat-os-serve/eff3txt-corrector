# eff3txt-corrector
Compresses words of a passphrase taken from the Electronic Frontier Foundation's 2nd short word list - a.k.a. the third overall word list - and corrects any detectable typos in the passphrase, as well as reporting said typos.

<https://www.eff.org/deeplinks/2016/07/new-wordlists-random-passphrases>

<https://www.eff.org/files/2016/09/08/eff_short_wordlist_2_0.txt>
